# Carevionix

Carevionix is an ASP.NET Core application project created to explore a healthcare-oriented software solution and a structured .NET application architecture.

## Purpose

This repository was created as a practical learning and demonstration project. It provides a foundation for organizing healthcare workflows, application services, and future database-backed features in a maintainable solution.

## How to Use

1. Install the .NET 8 SDK.
2. Review `Carevionix/appsettings.example.json` and create a local `Carevionix/appsettings.json` with your own development values. Do not commit the local configuration file.
3. From the repository root, run `dotnet restore`.
4. Start the application with `dotnet run --project Carevionix/Carevionix.csproj`.
5. Open the local URL shown in the terminal.

## Technology

- C#
- ASP.NET Core
- .NET 8

## Configuration

The repository includes `appsettings.example.json` as a safe template. Replace its placeholders locally with development-only values and keep credentials outside source control.
